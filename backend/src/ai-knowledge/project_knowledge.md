# SpendGuard capabilities
This demo reviews a description before signing; it verifies, signs, and executes no blockchain transaction. Input consists only of the request and these static files: no blockchain tools, reputation feed, trusted blacklist, history, balance, registry, price feed, route quote, or simulation.
The schema has five transaction fields, score 1-100, ALLOW/WARN/BLOCK, message, reasons, and recommendation; no approval/action/permission/confidence fields. Explain unsupported action details instead of inventing a transfer.
Server policy can raise risk for missing/invalid details, over-1000 token units, and direct secret/security attacks. NEAR accounts, access keys, intents, other chains, and wrapped assets may appear; actual state, ownership, permissions, and route support remain unverified.
